Trial 0: teaching an AI agent a shielding workflow

Can an AI agent, given a short onboarding guide and a practitioner's folder, set itself up to run radiation transport calculations and then solve a problem it has not seen? Trial 0 tested that on the OECD/NEA Kobayashi 3D benchmarks.

Setup used Kobayashi Problem 1, a 100 cm cube with a source, a low-density void and a shield. The agent meshed the CAD with Gmsh, solved it with OpenSn discrete ordinates, and cross-checked it with OpenMC Monte Carlo in one-group multigroup mode. It packaged that workflow as a small set of tools, each with its own checks.

The held-out test was Problem 3, a dog-leg duct through a shield. A fresh agent ran it end to end using only those tools. No reference answer was supplied and shell access was turned off. The results were then scored against the withheld benchmark table.

Physics traps caught during setup

Four real physics traps caught during setup
  1. Gmsh relabelled a solid after scaling. Converting the CAD from millimetres to centimetres left the shield solid named as the source. A volume check against the problem statement caught it before any solve.
  2. DAGMC treats a material called “void” as vacuum. The low-density region was transported as empty space with zero material volume. An independent volume check on the faceted geometry caught it, and neutral material tags fixed it.
  3. OpenMC tallies were normalised twice. A fixed-source run already scales tallies by source strength, so the first probe read about 1007 times the reference. A 1% gate on the flux at (5, 5, 5) caught it.
  4. Biased one-group weight windows were disabled, not shipped. Two MAGIC weight-window trials read 10 to 58% high in the deep shield while quoting 4 to 8% errors, and an 80 million particle analog run matched the exact reference. The agent turned weight windows off and logged the gap.
The Kobayashi problems are OECD/NEA 3D radiation transport benchmarks for simple geometries with void regions. Problem 1 is a shield around a void. Problem 3 is a dog-leg duct. These pages work on phone and desktop, in light or dark mode.
