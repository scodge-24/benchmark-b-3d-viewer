Trial 0

Teaching an AI agent a shielding workflow

Can an AI agent take a short written guide and a shielding engineer's problem folder, set up its own radiation transport workflow, and then solve a problem it has not seen? Trial 0 was a first test of that question on the OECD/NEA Kobayashi 3D benchmarks.

Setup used Kobayashi Problem 1, a 100 cm cube with a source, a low-density void region, and a shield. The agent meshed the CAD with Gmsh and solved the problem with OpenSn, a discrete ordinates (S_N) code. It cross-checked the result with OpenMC Monte Carlo in one-group mode on DAGMC geometry. It then packaged the workflow as seven tools that refuse an input with a missing or wrong unit.

The test was Kobayashi Problem 3, a dog-leg duct through a 60 × 100 × 60 cm shield. A fresh copy of the agent ran both cases, pure absorber and 50% scattering, with only those seven tools. It had no reference fluxes, and it could not run its own code or edit files. Its fluxes were then scored against the benchmark's reference values, which had been withheld.

A silent miss is a value outside the tolerance band that the tools accepted without a flag. The band is ±5% at the five points nearest the source and ±10% elsewhere, and it was fixed on Problem 1 before the test.

What Trial 0 did not test

No practising engineer took part. A second AI agent played the shielding practitioner, and the Kobayashi benchmarks are public, so the agent may have met them in its training data. Open-source codes stood in for a commercial chain. Trial 1 repeats the exercise with a practising shielding engineer and real industrial CAD.

Physics errors caught during setup

Each of these four errors gives wrong fluxes with no warning from the software. A check caught each one during setup.

Show the four errors
  1. Gmsh relabelled a solid after scaling. After the CAD was scaled from millimetres to centimetres, the shield solid carried the name of the source. A check of each solid's volume against the problem statement caught it.
  2. DAGMC treats a material named "void" as vacuum. OpenMC transported the low-density void region as empty space, with zero material volume. An independent volume check on the faceted geometry caught it. Neutral material names fixed it.
  3. OpenMC tallies were normalised twice. A fixed-source run already scales tallies by the source strength, so the first test run read about 1007 times the reference. A check that the flux at (5, 5, 5) is within 1% of the reference caught it.
  4. One-group weight windows gave biased fluxes. Two trials with MAGIC weight windows read 10% to 58% high in the deep shield while they quoted relative errors of 4% to 8%. An analog run of 80 million particles matched the exact reference. The agent turned weight windows off and recorded validated variance reduction as a gap.
The Kobayashi problems come from OECD/NEA report NSC/DOC(2000)4, a set of 3D radiation transport benchmarks for simple geometries with void regions. These pages work on a phone or a desktop, in light or dark mode.
